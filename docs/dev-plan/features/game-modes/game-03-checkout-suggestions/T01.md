# T01 — Frontend: Checkout Calculator Service + Display Component

## Metadata
- **Story:** GAME-03
- **Layer:** Frontend (Angular)
- **Status:** Planned
- **Agent:** Angular Developer
- **Depends on:** GAME-02 (Score entry)

## What to Build
Create a checkout calculator service that generates optimal checkout combinations for any score 2–170, and a display component that renders suggestions in the game UI. Service should be efficient (pre-computed or cached) and support toggling suggestions via settings.

## Definition of Done
- [ ] CheckoutCalculatorService calculates all valid checkouts for scores 2–170
- [ ] Service returns array of checkout combinations (e.g., [['T20', 'T20', 'Bull'], ['B20', 'D20']])
- [ ] Service handles edge cases: 169, 168, 166, 165, 163, 162, 159 (no valid checkout)
- [ ] Service returns empty array for scores < 2 or > 170
- [ ] Service includes only valid dart combinations (ring + multiplier)
- [ ] Service performance: lookup completes in < 10ms (cached)
- [ ] Component accepts `@Input() remainingScore: number` and `@Input() showSuggestions: boolean`
- [ ] Component displays suggestions only if: remainingScore ≤ 170 AND showSuggestions = true
- [ ] Component shows multiple options where available
- [ ] Component updates reactively as remaining score changes
- [ ] Settings integration: suggestions toggle stored in localStorage
- [ ] Component hidden when suggestions disabled or score > 170
- [ ] Accessibility: high contrast, readable font (min 14px)
- [ ] All unit tests pass

## Implementation Notes
- Pre-compute checkout table at service initialization or load from static data
- Use memoization or cache for repeated lookups
- Support both simple format ('T20') and descriptive format ('Triple 20')
- Consider visual formatting: highlight final dart (must be double)
- Component can be positioned as overlay or side panel
