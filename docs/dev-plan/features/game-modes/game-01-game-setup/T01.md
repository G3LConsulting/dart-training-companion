# T01 — Frontend: Game Setup Component with Mode-Specific Options

## Metadata
- **Story:** GAME-01
- **Layer:** Frontend (Angular)
- **Status:** Planned
- **Agent:** Angular Developer
- **Depends on:** INFRA-01 (Angular scaffold)

## What to Build
Create a reusable game setup component that allows users to configure and launch any game mode. The component displays mode-specific forms (501/301 with player count and rules, Cricket with mode and target score selection) and routes to the appropriate in-game view upon "Start".

## Definition of Done
- [ ] Component renders mode selector (radio buttons or cards for 501, 301, Cricket, Number Focus)
- [ ] Clicking each mode reveals mode-specific configuration form
- [ ] 501/301 form includes: player count toggle (1/2), double-in checkbox, double-out checkbox
- [ ] Cricket form includes: game mode selector (pass-and-play/solo), target score input (default 300)
- [ ] Cricket 2-player form includes: second player name input field
- [ ] Configuration summary displayed before start (shows all selected options)
- [ ] "Start" button navigates to correct in-game component with config passed as route params or service state
- [ ] "Cancel" or back button returns to home screen
- [ ] Invalid configurations prevent "Start" button activation (disabled state)
- [ ] Component passes all unit tests

## Implementation Notes
- Use Angular reactive forms for configuration inputs
- Leverage a GameModeService to manage and pass configuration between components
- Ensure smooth UX: mode selection → config form → summary → in-game transition
- Number Focus setup delegated to GAME-07 (link from setup screen)
- Consider responsive design for mobile/tablet screens
