# T02 — Frontend: Resume Prompt Component (Shown on App Init)

## Metadata
- **Story:** GAME-08
- **Layer:** Frontend (Angular)
- **Status:** Planned
- **Agent:** Angular Developer
- **Depends on:** T01, GAME-02/GAME-05/GAME-07 (Game components)

## What to Build
Create resume prompt modal/dialog component that appears on app initialization when saved game state is detected. Component offers "Resume" (restore session) and "Discard" (clear state) options with clear visual presentation.

## Definition of Done
- [ ] App initialization (app.component.ts or app initializer) checks for saved session
- [ ] If saved session exists: resume prompt displayed (modal/dialog)
- [ ] Prompt shows: game mode, target score (if applicable), turns/darts entered, time elapsed
- [ ] "Resume" button navigates to appropriate game component with saved state hydrated
- [ ] "Discard" button clears saved state and returns to home/mode selection
- [ ] Prompt has clear styling and readable text (large buttons, high contrast)
- [ ] Prompt is not dismissible without choosing (block background)
- [ ] Resume restores exact state: all turns, current player, undo history
- [ ] Component integrates with AutoSaveService (T01) and game state services
- [ ] Component handles async state loading (loading indicator if needed)
- [ ] Only shows once per app open (dismiss state tracked)
- [ ] Works on mobile and desktop
- [ ] Accessibility: ARIA labels, keyboard support
- [ ] All unit tests pass

## Implementation Notes
- Use Angular service initializer to check saved session on app boot
- Consider using Material Dialog or custom modal
- Show session preview (game info, progress) before resume
- Confirmation dialog if user tries to start new game with unsaved session
- Clear visual hierarchy: Resume (primary), Discard (secondary)
- Consider timeout: if user doesn't respond in 5 minutes, auto-discard and proceed
