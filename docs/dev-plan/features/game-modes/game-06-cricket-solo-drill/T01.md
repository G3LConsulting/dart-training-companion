## What to Build
Create Cricket solo drill component that reuses Cricket scoreboard and game logic for single-player mode. Component displays target score benchmark, automatically ends when all numbers closed, and displays results.

## Definition of Done
- [ ] Component reuses Cricket scoreboard from GAME-05 (shared component or service)
- [ ] Component displays single player (no opponent)
- [ ] Target score displayed prominently (default 300, from config)
- [ ] Current score displayed and updated in real-time
- [ ] Darts can be entered per turn (using score input or dart buttons)
- [ ] Turn submission updates marks and score
- [ ] Game automatically ends when all 7 numbers (15–20, Bull) closed
- [ ] Results component shows: total score, turns, duration, marks breakdown
- [ ] Results include comparison to personal history (best/average for solo Cricket)
- [ ] Navigation options: "New Drill", "Change Mode", "Home"
- [ ] No pass/fail logic (session always saves)
- [ ] Responsive layout for mobile and desktop
- [ ] All unit tests pass

## Implementation Notes
- Can extend CricketGameComponent with solo mode flag
- Reuse CricketStateService with player count = 1
- Display target score as reference line (not achievement requirement)
- Show progress toward target (e.g., "278/300")
- Consider shared results component for both 2-player and solo
