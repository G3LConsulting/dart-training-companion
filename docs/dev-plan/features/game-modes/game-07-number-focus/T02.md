# T02 — Frontend: Number Focus In-Session Component

## Metadata
- **Story:** GAME-07
- **Layer:** Frontend (Angular)
- **Status:** Planned
- **Agent:** Angular Developer
- **Depends on:** T01, T04

## What to Build
Create main in-session component for Number Focus mode that displays target number, dart counter, live hit breakdown, accuracy percentage, and 4 outcome buttons (Triple, Double, Single, Miss). Component manages dart entry, undo, and auto-completion.

## Definition of Done
- [ ] Component displays target number prominently (large, centered)
- [ ] Dart counter shows: "X / Y" (e.g., "23 / 50")
- [ ] 4 large buttons: Triple, Double, Single, Miss (min 80px, touch-friendly)
- [ ] Each button click records dart outcome and increments counter
- [ ] Running breakdown displays: Triple count, Double count, Single count, Miss count
- [ ] Running breakdown shows both counts and percentages (e.g., "Triples: 5 (22%)")
- [ ] Live accuracy % calculated: (hits / total darts) * 100 (where hits = T + D + S)
- [ ] Accuracy updates in real-time with each dart
- [ ] Undo button reverts last dart (one level); disabled if no darts entered
- [ ] Session auto-ends when dart counter reaches set size
- [ ] Smooth transition from session to results component
- [ ] Large fonts and high contrast for visibility
- [ ] Responsive layout for landscape and portrait
- [ ] All unit tests pass

## Implementation Notes
- Use large touch targets (min 80x80px for buttons)
- Use bright colors and high contrast for buttons (different color per outcome)
- Consider haptic feedback on mobile (optional)
- Prevent accidental touches with debounce/throttle
- Display progress bar showing darts entered vs total
- Consider animations for dart entry feedback
