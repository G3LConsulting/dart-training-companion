# T04 — Frontend: Number Focus Game State Service

## Metadata
- **Story:** GAME-07
- **Layer:** Frontend (Angular)
- **Status:** Planned
- **Agent:** Angular Developer
- **Depends on:** GAME-01

## What to Build
Create Number Focus game state service that manages dart entries, calculates accuracy and weighted accuracy in real-time, handles undo, and auto-ends session at set size. Service provides reactive observables for component binding.

## Definition of Done
- [ ] Service initializes from setup config (target number, dart count)
- [ ] Service exposes observables: `dartCount$`, `breakdown$`, `accuracy$`, `weightedAccuracy$`, `sessionOver$`, `canUndo$`
- [ ] `addDart(outcome: 'Triple' | 'Double' | 'Single' | 'Miss'): void` records dart
- [ ] Service maintains immutable state (no mutations)
- [ ] Breakdown tracks: { triples: #, doubles: #, singles: #, misses: # }
- [ ] Accuracy calculated: (triples + doubles + singles) / totalDarts * 100
- [ ] Weighted accuracy calculated: (triples*3 + doubles*2 + singles*1) / (totalDarts*3) * 100
- [ ] Accuracy updates reactively after each dart
- [ ] `undo(): void` reverts last dart (one level only)
- [ ] Undo disabled when no darts entered
- [ ] Auto-end detection: session over when dartCount reaches setSize
- [ ] `getResults(): Observable<NumberFocusResults>` exposes final stats
- [ ] Results include: target, set size, breakdown, accuracy, weighted accuracy, duration
- [ ] Support hydration from auto-saved state (GAME-08)
- [ ] All unit tests pass

## Implementation Notes
- Use RxJS BehaviorSubject for reactive state
- Formulas: Accuracy = (T+D+S)/Total*100, WeightedAccuracy = (T*3+D*2+S*1)/(Total*3)*100
- Performance: accuracy calculation must be < 10ms per dart
- Maintain turn history for undo (immutable array)
- Consider caching previous states for undo efficiency
