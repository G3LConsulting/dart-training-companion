# T03 — Frontend: Number Focus Results Component

## Metadata
- **Story:** GAME-07
- **Layer:** Frontend (Angular)
- **Status:** Planned

## What to Build
Create results component that displays final session statistics (breakdown, accuracy, weighted accuracy), compares to personal best for the target number, and provides navigation options (new set, change number, home).

## Definition of Done
- [ ] Component displays breakdown: Triples (count, %), Doubles (count, %), Singles (count, %), Misses (count, %)
- [ ] Component displays: Accuracy % = (Hits / Total Darts) * 100
- [ ] Component displays: Weighted Accuracy % = (Triples*3 + Doubles*2 + Singles*1) / (Total*3) * 100
- [ ] Component shows: target number, set size, session duration
- [ ] Component fetches personal best for this target number (best accuracy, best weighted accuracy)
- [ ] Comparison shows: PB accuracy, PB weighted accuracy, improvement indicator
- [ ] Highlights new PBs with visual indicator (badge, color, animation)
- [ ] Breakdown displayed as table, chart, or list with good readability
- [ ] Navigation buttons: "New Set" (same number), "Change Number", "Home"
- [ ] Optional: show historical trend (last 5 sessions for this number)
- [ ] Results can be shared (optional social feature)
- [ ] Responsive layout for mobile and desktop
- [ ] All unit tests pass

## Implementation Notes
- Fetch PB data from API or cached state
- Formulas: Accuracy = (T+D+S)/Total * 100, Weighted = (T*3+D*2+S*1)/(Total*3)*100
- Consider chart visualization (bar chart for breakdown, line chart for trend)
- Celebration animation for new PB
- Consider export/save results feature (optional)
- Share session results (optional social media integration)
