## Definition of Done
- [ ] Test: Standard session flow — 50 darts, breakdown, accuracy calculated
- [ ] Test: Accuracy calculation — example: 40 hits in 50 darts = 80% accuracy
- [ ] Test: Weighted accuracy calculation — example: T=15, D=10, S=15, M=10 = (15*3+10*2+15*1)/(50*3)*100 = 76%
- [ ] Test: Undo functionality — reverts last dart, counts and accuracy recalculated
- [ ] Test: Undo disabled when no darts entered
- [ ] Test: Undo one level only
- [ ] Test: Auto-end detection — session ends at set size (e.g., 50 darts)
- [ ] Test: Auto-end triggers results transition
- [ ] Test: State maintains immutability
- [ ] Test: Breakdown counts accurate after each dart
- [ ] Test: Edge case — all misses (0% accuracy)
- [ ] Test: Edge case — all triples (100% accuracy, 100% weighted)
- [ ] Test: Edge case — mixed outcomes with correct percentages
- [ ] Test: Session initialization from config (target number, dart count)
- [ ] Test: Results include all required stats (accuracy, weighted, breakdown)
- [ ] Test: Component displays accuracy and weighted accuracy correctly
- [ ] Test: Setup component number selection works (1–20, Bull)
- [ ] Test: Setup component dart count selection (10–200, step 10)
- [ ] Test: Results component displays breakdown percentages
- [ ] Test: Results component fetches and displays PB comparison
- [ ] All tests pass with >85% code coverage
