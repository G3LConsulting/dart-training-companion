# T01 — Frontend: Number Focus Setup Component

## Metadata
- **Story:** GAME-07
- **Layer:** Frontend (Angular)
- **Status:** Planned
- **Agent:** Angular Developer
- **Depends on:** GAME-01 (Game setup flow)

## What to Build
Create Number Focus setup component that allows users to select target number (1–20 or Bull) and dart count (10–200 in increments of 10), with visual configuration summary and start button.

## Definition of Done
- [ ] Component displays number selector: buttons 1–20 + Bull (21 total)
- [ ] Selected number highlighted visually
- [ ] Component displays dart count selector: slider or increment/decrement (10–200, step 10)
- [ ] Default dart count = 50
- [ ] Configuration summary shows: target number and dart count before start
- [ ] "Start" button enabled only when both number and dart count selected
- [ ] "Cancel" or back button returns to game mode selection
- [ ] Responsive layout: works on mobile (large touch targets, min 48x48px)
- [ ] Visual feedback on selection (highlight, color, or check mark)
- [ ] Component passes configuration to session component (via service or route params)
- [ ] Accessibility: ARIA labels, focus management
- [ ] All unit tests pass

## Implementation Notes
- Use grid or flex layout for number buttons
- Consider visual organization: numbers 1–20 in grid, Bull as separate large button
- Store selected config in NumberFocusStateService
- Validate selections before enabling Start button
- Consider remembering last used number/dart count (localStorage)
