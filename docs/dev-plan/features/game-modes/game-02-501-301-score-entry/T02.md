## Metadata
- **Story:** GAME-02
- **Layer:** Frontend (Angular)
- **Status:** Planned
- **Agent:** Angular Developer

## What to Build
Create the main in-game component for 501 and 301 modes that displays the game scoreboard, integrates the score input widget, detects busts, supports undo, and manages turn transitions. Supports both 1-player and 2-player (pass-and-play) scenarios.

## Definition of Done
- [ ] Scoreboard displays: current player name, remaining score, current turn score, round number
- [ ] 2-player mode shows both players' information (current/opponent)
- [ ] Score input widget integrated; on score submission: bust detection and turn completion triggered
- [ ] Remaining score calculated correctly (e.g., 501 - 20 - 19 - 40 = 422)
- [ ] Bust detection: score < 1 OR (double-out enabled AND final score is not on double)
- [ ] Bust notification displayed clearly, turn voided, state reverted to pre-turn
- [ ] Undo button reverts to previous turn state (one level only); disabled if no previous state
- [ ] 2-player: turns alternate, player indicator updates after each turn
- [ ] Game continues until checkout (score reaches exactly 0 on double) or game abandoned
- [ ] Responsive layout: large text for visibility, touch-friendly buttons
- [ ] All unit tests pass (standard game flow, bust scenarios, undo, 2-player switching)

## Implementation Notes
- Use GameStateService (T03) for state management
- 501 and 301 can share logic with mode param
- Track turn history for undo functionality
- Consider visual animations for bust/undo feedback
- Ensure clear player identification in 2-player mode (names, colors, or icons)
- Persist state via GAME-08 (auto-save)
