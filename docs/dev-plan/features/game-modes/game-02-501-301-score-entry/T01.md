# T01 — Frontend: Score Input Widget (Numeric Keypad + Segment-by-Segment)

## Metadata
- **Story:** GAME-02
- **Layer:** Frontend (Angular)
- **Status:** Planned
- **Agent:** Angular Developer
- **Depends on:** GAME-01 (Game setup)

## What to Build
Create a reusable score input component that supports two input modes: numeric keypad (0-3 digits, default) and segment-by-segment entry (ring selection, multiplier selection). Component emits score value to parent and supports both touch and keyboard input. Performance critical: must respond within 100ms.

## Definition of Done
- [ ] Numeric keypad mode displays 0-9 buttons, clear/backspace, submit button
- [ ] Segment-by-segment mode displays ring selector (20, 19, 18, etc., bull) and multiplier selector (triple, double, single, miss)
- [ ] Input method can be toggled via settings (stored in localStorage)
- [ ] Component accepts `@Input() inputMode: 'keypad' | 'segment'`
- [ ] Component emits `@Output() scoreEntered: EventEmitter<number>`
- [ ] Keypad mode accepts 0-180 range (validates and clears invalid input)
- [ ] Segment mode calculates and emits correct score (ring * multiplier)
- [ ] Keyboard support: number keys 0-9, Enter to submit, Backspace to clear
- [ ] Touch support: large buttons (min 48x48px) with visual feedback
- [ ] Input validation: prevents invalid entries, shows error feedback
- [ ] Performance: all interactions complete within 100ms (measured)
- [ ] All unit tests pass

## Implementation Notes
- Use reactive forms or direct input binding
- Leverage RxJS debounce/throttle for performance-sensitive operations
- Consider accessibility: ARIA labels, focus management
- Large font sizes and high contrast for visibility
- Both input modes should feel natural and fast
- Consider haptic feedback on mobile (optional enhancement)
