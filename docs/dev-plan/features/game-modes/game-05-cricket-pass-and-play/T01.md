# T01 — Frontend: Cricket Scoreboard Component with Marks Tracking

## Metadata
- **Story:** GAME-05
- **Layer:** Frontend (Angular)
- **Status:** Planned
- **Agent:** Angular Developer
- **Depends on:** GAME-01 (Cricket 2-player config)

## What to Build
Create Cricket scoreboard component that displays marks per number per player, point totals, and game state. Component shows visual indicators for closed/open numbers, allows dart entry per turn, and detects game completion.

## Definition of Done
- [ ] Scoreboard displays all numbers: 15, 16, 17, 18, 19, 20, Bull
- [ ] Each number has three columns: Player 1 marks, Player 2 marks, Points
- [ ] Marks shown as: 0–3 marks using visual indicators (X, XX, XXX or circles)
- [ ] Closed numbers highlighted (e.g., bold, different color)
- [ ] Points column shows score only for open numbers
- [ ] Running total points shown for each player
- [ ] Current player clearly indicated (e.g., highlighted row, player name color)
- [ ] Dart entry buttons or input widget integrated (S, D, T, Miss)
- [ ] Turn submission updates marks and calculates points
- [ ] Game completion detection: all numbers closed by both players
- [ ] Visual feedback for turn completion (animation, state update)
- [ ] Undo button reverts to previous turn state
- [ ] Responsive layout: fits mobile screens
- [ ] Accessibility: high contrast, readable font sizes
- [ ] All unit tests pass

## Implementation Notes
- Consider using a table or grid layout for scoreboard
- Use visual elements (X marks, circles) for mark indicators
- Highlight current player with color or border
- Calculate points in real-time as marks added
- Support both landscape and portrait orientations
- Consider separating scoreboard display from game logic
