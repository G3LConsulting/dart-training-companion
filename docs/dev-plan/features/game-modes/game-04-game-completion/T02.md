# T02 — Frontend: Post-Game Summary Component

## Metadata
- **Story:** GAME-04
- **Layer:** Frontend (Angular)
- **Status:** Planned
- **Agent:** Angular Developer
- **Depends on:** GAME-02 (Game data)

## What to Build
Create post-game summary component that displays game statistics, comparison to personal best, and navigation options (new game or home). Component receives game session data and calculates summary metrics.

## Definition of Done
- [ ] Component displays: game mode, total turns, 3-dart average, highest turn, total score
- [ ] Component shows: finish time (for timed modes), duration of game
- [ ] For 501/301: displays checkout scored (final dart combination) if applicable
- [ ] For 2-player: shows winner name and individual stats for each player
- [ ] Component displays personal best comparison: PB 3-dart average, PB highest turn (with dates)
- [ ] Component highlights achievements (new PB, improvement over last game)
- [ ] Buttons: "New Game" (same mode), "Change Mode", "Home"
- [ ] Component receives session data via @Input or resolver
- [ ] Component calculates stats from game data
- [ ] Responsive layout: readable on mobile and desktop
- [ ] Celebration animation for milestones (optional enhancement)
- [ ] All unit tests pass

## Implementation Notes
- Use separate layout component or module for post-game view
- Fetch personal best data from API or state service
- Consider loading state while PB data is fetched
- Format numbers clearly (e.g., 35.67 for 3-dart average)
- Use color/icons to highlight PBs and achievements
- Smooth transition from in-game to post-game view
