## What to build

Implement RequestPasswordResetCommand and ResetPasswordCommand with handlers and validators. RequestPasswordResetCommand accepts email, generates password reset token via UserManager, sends email with reset link containing token and email. Always returns 200 (never enumerate whether email exists). ResetPasswordCommand accepts email, token, and newPassword, validates token, resets password via UserManager. Add POST /api/auth/forgot-password and POST /api/auth/reset-password endpoints to AuthController. Include proper error handling (invalid token, expired token, weak password).

## Definition of done

- [ ] RequestPasswordResetCommand accepts email
- [ ] RequestPasswordResetCommandHandler: generates token via UserManager.GeneratePasswordResetTokenAsync()
- [ ] Sends email with reset link: `{baseUrl}/reset-password?token={token}&email={email}`
- [ ] Always returns 200 (success or not; don't enumerate accounts)
- [ ] ResetPasswordCommand accepts email, token, newPassword
- [ ] ResetPasswordCommandValidator: password >= 8 chars, email required, token required
- [ ] ResetPasswordCommandHandler: validates token via UserManager.ResetPasswordAsync()
- [ ] On success: password updated, all refresh tokens revoked (force re-login)
- [ ] POST /api/auth/forgot-password returns 200 always
- [ ] POST /api/auth/reset-password returns 200 on success, 400 for invalid token/weak password
- [ ] Invalid/expired token returns clear error: "Invalid or expired reset link"
- [ ] All tests pass; no compilation errors

## Implementation notes

- RequestPasswordResetCommand must not reveal whether email exists (always 200)
- Silently fail if email not found; send dummy success response
- Password reset token generated by UserManager; expires per ASP.NET Core Identity defaults (typically 1 day, configurable)
- ResetPasswordCommand should accept token in request body or query param per design
- Consider: Revoke all refresh tokens on password reset to force user back to login
- Use UserManager.ResetPasswordAsync(user, token, newPassword) for actual reset
- Check UserManager result for errors (token invalid, password too weak)
